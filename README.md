# 3D Universalis - Landing Pages

Bilingual (FR/EN) landing pages for 3D Universalis services. Built with React 18, React Router v6, and Vite.

## Available Scripts

### `npm run dev`

Runs the app in development mode.
Open [http://localhost:5173/3du-landings-pages/](http://localhost:5173/3du-landings-pages/) to view it in the browser.

### `npm run build`

Builds the app for production to the `build` folder.

### `npm run preview`

Serves the production build locally for testing.

## Deployment

The project is deployed to GitHub Pages via GitHub Actions. Every push to `master` triggers a build and deploy.

Live URL: https://3d-universalis.github.io/3du-landings-pages/
